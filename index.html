FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

Account requirements depend on the service. An account is generally used to save and manage links, customise them, and view analytics.

Are the shortened links permanent? Will they expire?

Link lifetime depends on the service and plan. Check the expiration settings before sharing a link that needs to remain available.

Are there any limitations on the number of URLs I can shorten?

Limits depend on the plan you choose. Compare the plans above for the features shown in this design.

Can I customize the shortened URLs to reflect my brand or content?

Custom aliases and branded domains can make a link more recognisable and relevant to your audience.

Can I track the performance of my shortened URLs?

A link-management service can record clicks and display analytics to help you understand how your links are used.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

A short link can hide its destination. Use trusted services and check unfamiliar links before opening them. Security features depend on the provider.

What is a QR code and what can it do?

A QR code is a scannable pattern that can store a website address. Scanning it with a compatible phone camera opens the linked destination.

Is there an API available for integrating the URL shortening service into my own applications or websites?

The Teams plan in this design lists API access. This landing-page preview does not include a live API.
